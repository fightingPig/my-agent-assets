# UI asset source

The reusable source lives in this directory. See
`../../docs/ui-assets/README.md` for the design contract, adoption guide and
canonical visual references.

- `tokens.css`: portable foundations.
- `contracts.ts`: framework-light structural UI types.
- `components/ProviderMark.tsx`: portable provider identity primitive.
- `components/StatusFilterMenu.tsx`: keyboard-complete application-layer filter popover.
- `status.ts`: shared status-copy to semantic-tone mapping.
- `mounts/model.ts`: pure mount presentation model.
- `mounts/MountDraftContext.tsx`: preview-first frontend draft queue.
- `mounts/MountMatrix.tsx` and `mounts/demo-data.ts`: desktop application adapters.
- `edition.css`: page-pattern integration layer.
